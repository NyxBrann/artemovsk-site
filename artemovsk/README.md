# 🏙️ Артёмовск — История городов Республики

Многостраничный статический сайт об Артёмовске (до 1924 г. — Бахмут) — одном из старейших городов Донбасса.

> ⚠️ **Важно:** материалы носят историко-справочный характер и описывают город до боевых действий 2022–2023 гг. Сейчас Артёмовск практически полностью разрушен; раздел об инфраструктуре дополнен планами восстановления.

---

## 📌 Назначение проекта

Учебный проект по дисциплине «Веб-технологии». Цель — показать навыки:

- семантической HTML5-разметки;
- современной CSS-вёрстки (position, float, псевдоклассы, псевдоэлементы, адаптивность);
- связывания многостраничного сайта единым меню.

---

## 🛠️ Использованные технологии

- **HTML5** — семантика: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<figure>`, `<figcaption>`, `<details>`, `<summary>`, `<time>`, `<mark>`, `<progress>`, `<iframe>`.
- **CSS3** (`css/style.css`):
  - позиционирование: `static`, `relative`, `absolute`, `fixed`, `sticky`;
  - обтекание: `float` + `shape-outside`;
  - селекторы: тег, класс, id, `*`, по атрибуту;
  - комбинаторы: потомки, дочерние, соседние, общие;
  - псевдоклассы: `:hover`, `:active`, `:focus`, `:link`, `:visited`, `:first-child`, `:last-child`, `:nth-child(even)`, `:not()`, `:required`, `:valid`, `:invalid`, `:placeholder-shown`;
  - псевдоэлементы: `::before`, `::after`;
  - адаптивность: `@media (max-width: 768px)`, `(max-width: 480px)`;
  - Grid и Flexbox.
- **Google Fonts** — Montserrat, Open Sans.
- **OpenStreetMap** — карта через `<iframe>`.

Без конструкторов сайта и JS-фреймворков.

## 📄 Структура страниц

| Файл | Назначение |
